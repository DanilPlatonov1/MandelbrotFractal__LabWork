# MandelbrotFractal__LabWork

## 1. О проекте
Данный проект представляет собой приложение для визуализации фракталов с использованием параллельных вычислений на Python.
Основная цель работы - продемонстрировать применение многопроцессорной обработки данных для ускорения вычислений при генерации сложных изображений.

Реализовано:
- графическое окно (GUI)
- выбор типа фрактала
- изменение разрешения
- zoom выделением мыши
- сохранение изображения в файл

## 2. Что такое Мандельброта
Множество Мандельброта - это математический фрактал, основанный на поведении последовательности комплексных чисел.
Для каждой точки комплексной плоскости применяется итерационная формула:
zₙ₊₁ = zₙ² + c
Если последовательность остаётся ограниченной, точка принадлежит множеству. Если значения стремятся к бесконечности - не принадлежит.

## 3. Как работает программа
Программа выполняет следующие этапы:
1) Каждому пикселю изображения сопоставляется точка на комплексной плоскости
2) Для каждой точки вычисляется поведение последовательности по фрактальной формуле
3) В зависимости от скорости “разбегания” последовательности выбирается цвет пикселя
4) Изображение формируется построчно

Параллельная версия работы: изображение делится на строки, каждая часть которой обрабатывается отдельным процессом и затем результаты объединяются в финальное изображение.
